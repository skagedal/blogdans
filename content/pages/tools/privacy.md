*Last updated 23 September 2026.*

**skagedal-tools is a personal tool with one user, and that user is me.** It runs on my own machine, on my own data. It is not a product, it is not offered to anyone, and there is nothing to sign up for.

This page exists because services I register the tool with ask for a privacy policy URL, and a dead link seemed worse than an honest page.

## Who is responsible

Simon Kågedal Reimer, Uppsala, Sweden. [skagedal@gmail.com](mailto:skagedal@gmail.com).

## What it does with data

The tool works on my own data, using access I have granted myself, and processes it locally.

- Nothing is collected from anyone else.
- Nothing is published, sold, shared or sent onward.
- Nothing goes to any analytics, advertising or machine-learning service.
- There is no server holding a copy. It stays on my own machine and in private storage that only I can read.

Where a provider sits between me and my own data, that provider's own privacy notice governs what they do in the middle. Access is granted by my own authentication and I can withdraw it at any time.

## How long

Indefinitely. It is mine and I keep it.

## If you think this concerns you

It almost certainly does not. But if you believe data about you has ended up here, write to the address above and I will tell you what there is and remove it on request.

## This website

[skagedal.tech](/) is a blog. It sets a cookie only if you sign in to leave a comment, and the server keeps ordinary access logs, as web servers do.
